# Loremarket

A living marketplace for fantasy role-playing games. Loremarket gives players a simple way to search for items, while merchants can shape each market through changing prices and availability. It adds a dynamic layer to campaigns and makes managing in-game trade easier for game masters.

## Planned features

- Let game masters create worlds and define their economies.
- Add a gamified experience where players can create and use resources, with changes that affect everyone in the game.

## Quick Start

```bash [Terminal]
npm create nuxt@latest -- -t ui
```

## Setup

Make sure to install the dependencies:

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Build the application for production:

```bash
pnpm build
```

Locally preview production build:

```bash
pnpm preview
```

## Renovate integration

Install [Renovate GitHub app](https://github.com/apps/renovate/installations/select_target) on your repository and you are good to go.
